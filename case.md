# Описание кейса

Вы - сервис рассрочки.
К вам пришел ЦБ с предложением вступить в пилотирование платформы смарт-контрактов для оплаты Цифровым Рублем через Платформу Смарт-контрактов.
У вас есть как минимум проблема неоплат и отвязки счетов СБП и блокировки карт после оформления рассрочки.

# Вопросы и указания

+ Как смарт-контракты могут помочь вам?
+ Придумайте верхнеуровневую схему оплаты по смарт-контракту и опишите её. В решении важно описать архитектуру и представить sequence-диаграмму процесса. 
+ Опишите клиентский путь. При желании можете сделать и примеры интерфейса (использовать ИИ для этого можно, в задании укажите модель, которую использовали).
+ Если требуются допущения для решения задачи - смело описывайте.
+ Какие параметры смарт-контрактов вам особенно важны?
+ Какие видите риски решения?
+ Какие остались открытые вопросы?
